# ⚡ TaskFlow (업무용 경량 Todo 리스트)

사내 보안 환경 및 비인가 프로그램 설치 제약이 있는 업무 환경에서도 안전하게 사용할 수 있는 **초경량 크로스 플랫폼(Windows / macOS) 파이썬 Todo 프로그램**입니다.

---

## 🌟 핵심 기능

1. **마감일 & D-Day 자동 계산 및 정렬**:
   - `오늘`, `내일`, `+3`, `+7`, `MM-DD`, `YYYY-MM-DD` 등 자연어 및 축약 날짜 입력을 지원합니다.
   - **가장 임박한 일정(D-Day, D-1, 기한 초과 등)이 항상 상단에 자동 정렬**됩니다.
2. **시각적 페이드아웃 (Fade-out) 효과**:
   - 상단에 있는 긴급한 항목일수록 선명하고 밝은 화이트 톤으로 표시됩니다.
   - **아래로 내려갈수록 배경색에 가깝게 부드럽게 페이드아웃(투명도 상승 효과)** 되어 중요도가 낮음을 직관적으로 알 수 있습니다.
3. **완료 태스크 취소선 & 하단 이동**:
   - 완료된 태스크는 체크 표시(`☑`)와 함께 **텍스트 취소선(Strikethrough)** 처리되어 최하단으로 정리됩니다.
4. **키보드 중심 100% 조작**:
   - 마우스에 손을 댈 필요 없이 모든 작업(추가, 선택, 완료, 수정, 삭제)을 키보드로 조작할 수 있습니다.
5. **윈도우 & Mac 완벽 호환**:
   - 파이썬 표준 라이브러리(`tkinter`)만 사용하여 별도의 `pip install` 없이 즉시 실행됩니다.
   - OS에 맞춰 단축키(`Ctrl` vs `Cmd`), 폰트(`Segoe UI` vs `SF Pro`)가 자동 전환됩니다.
6. **윈도우 부팅 시 자동 실행 & 창 위치 기억**:
   - 상단 `🚀 자동시작` 버튼 클릭 한 번으로 윈도우 시작프로그램 등록/해제가 가능합니다.
   - 창을 닫아도 배치했던 화면 위치와 크기가 그대로 유지됩니다.

## ⌨️ 키보드 단축키 가이드

| 단축키 (Windows) | 단축키 (macOS) | 기능 설명 |
| :--- | :--- | :--- |
| **`Ctrl + N`** | **`Cmd + N`** | 언제든지 **새 할 일 입력창으로 포커스 이동** |
| **`Enter`** (입력창) | **`Enter`** (입력창) | 새 할 일 등록 (연속 등록 가능) |
| **`↓ (아래 방향키)`** 또는 **`Esc`** | **`↓`** 또는 **`Esc`** | **입력창에서 할 일 목록(리스트)으로 포커스 이동** |
| **`Enter`** (빈 입력창) | **`Enter`** (빈 입력창) | 빈 상태에서 엔터 시 바로 목록으로 이동 |
| **`Tab`** / **`Shift+Tab`** | **`Tab`** / **`Shift+Tab`** | 할 일 입력 ↔ 마감일 입력 ↔ 목록 순환 이동 |
| **`↑ / ↓`** | **`↑ / ↓`** | 목록 내에서 항목 위/아래 탐색 |
| **`Space`** | **`Space`** | 선택한 항목 **완료/미완료 토글** (취소선 적용) |
| **`F2`** | **`F2`** | 선택한 항목 내용 및 마감일 **수정** |
| **`Delete`** (Mac: `Delete`/`Backspace`) | **`Delete`** / **`Backspace`** | 선택한 항목 **삭제 확인창 호출** (`Enter`/`Y`/`ㅛ` 삭제, `Esc`/`N`/`ㅜ` 취소, `←/→` 이동) |
| **`Ctrl + T`** | **`Cmd + T`** | 화면 최상단 고정 (**Always on Top**) 토글 |
| **`Ctrl + D`** | **`Cmd + D`** | **라이트 / 다크 테마 전환** |
| (창 닫기 버튼 `✕`) | **`Cmd + Q`** | 프로그램 종료 (창 위치 및 데이터 자동 저장) |

## 📅 마감일 입력 꿀팁

입력창 오른쪽의 마감일 칸에 다음과 같이 편하게 입력하실 수 있습니다:
- `오늘` 또는 `0` : 오늘 마감 (D-Day)
- `내일` 또는 `+1` : 내일 마감 (D-1)
- `+3` 또는 `3일` : 오늘로부터 3일 뒤 마감 (D-3)
- `09-25` 또는 `9/25` : 이번 연도 9월 25일
- `2026-09-25` : 특정 연도 마감일
- 빈칸 : 기한 없음(상시)으로 분류되어 하단 배치

## 🚀 실행 방법

- **더블 클릭 실행 (추천)**: [TaskFlow.vbs](file:///C:/Users/kty/tmp/todo/TaskFlow.vbs) 파일을 더블 클릭하면 검은색 콘솔 창 없이 깔끔하게 GUI만 실행됩니다.

  ```powershell
  pythonw todo.py
  ```

- 터미널에서:
  ```bash
  python3 todo.py
  ```
